# Human-Approved Spec（当前实施版）

本文档是当前项目的执行源（source of execution）。

## 当前已确认的高层原则

1. Mnemosyne 是“记忆系统元 Agent”，职责是为不同场景设计、交付、维护和迭代外部持久记忆系统。
2. 采用类似冯诺伊曼结构的外部记忆架构：模型可替换、外部文件/Git 仓库作为长期存储、规则与流程作为可演化指令层。
3. 模型内部 memory 仅作为缓存或辅助上下文，不作为唯一真相源。
4. 新想法不能自动覆盖当前实施版；重大更新需经用户确认后才能写入本实施版。

## 执行源层次边界

- 原文是证据，不是执行源。
- 候选需求不是执行源。
- 模型摘要不是执行源。
- 只有用户确认后的实施版才是执行源。
