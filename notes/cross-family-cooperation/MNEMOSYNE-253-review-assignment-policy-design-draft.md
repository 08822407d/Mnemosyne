## 2. 方案：按产物类别指派审核者（非轮换、非单方）

| 类 | 产物 | 强制/默认 | 审核者 | 依据 |
|---|---|---|---|---|
| A | 执行源、guard、权限、署名规则文本 | **强制异族**（D-08） | 非起草族；结构层批判优先 GPT-Pro，机械一致性（引用/编号/diff）由 Claude Code 核 | §1 第 2/3 行 |
| B | 机械核验产物（行数、哈希、diff 映射、考古统计、索引一致性） | 默认 | Claude Code 执行；GPT 侧按 Pro 自检修正做"至少一次异构抽样重算" | §1 第 3 行 |
| C | 声称/计数/范围陈述（转交包、清单、结算文本） | 默认 | GPT-Pro 复核；同族自查不算 | C-14 |
| D | 状态/新鲜度扫描 | 默认 | 未产生该状态的一族；Claude Code 默认执行扫描、GPT 侧判"该不该更新" | P-01/02 |
| E | 重大验证 PASS / gate 关闭 | **强制异族**（D-08） | 非执行族 | D.4 |
| F | 实验评分 | 强制 | 评分者 ≠ 执行者族；细则预冻结；Owner 可请另一族复核评分 | C-16 教训 |
| G | typo/格式/固定机械动作 | 免 | 无异族复核 | D-08 |
| H | 登记簿自记条目（C/P 自述） | 周期 | 对方族每整编周期做一次外部视角批判 | Pro 已做首轮 |

五条原则：

1. **不轮换**：由产物类别与弱项匹配决定审核者；轮换只作同类别平局时的打破器。
2. **双向性**：每个整编周期执行一次 EXP-1 式双向抽检（同一冻结小任务双族执行、双盲互评 diff），产出差异矩阵入登记簿——保证"互审"不因分工表而退化为单向。
3. **自审不独立**：同族复核须按 §19 标注 independence limitation；不得以"两次自查"冒充异族复核。
4. **额度意识**：Pro 额度稀缺——只用于 A/C/E/H 类；B/D 大宗由 Claude Code 承担；G 类零复核。
5. **次档分层（衔接 #265 TODO 3）**：B/D/G 类可由次档模型（Opus / 非 Pro 的 Sol）执行，A/C/E/F 类需前沿档；TODO 3 的验证就嵌在这里做——先在 B/D 类任务上让次档执行并与前沿档结果对比，结果入登记簿 8 字段。

## 5. 自我批判

1. **素材不对称**：本轮 GPT 侧被 Fable 评审得多（历史考古），Claude 侧只被 Pro 审过一轮——能力画像的样本量偏斜，§1 表应视为首版先验而非结论。
2. **工具差异易被误读为能力差异**：Claude Code 的机械优势来自本地 shell；若 ChatGPT 在 Codex/Work 表面获得执行环境，B/D 类默认应重评——表中已标注。
3. **利益相关声明**：起草者是被分派的一方，"Claude 承担大宗机械"既是能力事实也可能含省事倾向；对冲：本稿本身属 A 类，按自身规则须 Pro 异族复核后才可采纳。
4. **原则 2 的成本**：每周期一次 EXP-1 抽检各耗两族一次会话，若周期缩短会与"额度意识"冲突——参数留给首个周期校准。
