## 5. Architecture principles

- **P1 External truth.** Versioned external files are the only durable substrate; model context and platform memory are caches, never truth [N01,N09; S-01,S-03; CB-17…21].
- **P2 Single operative authority.** Exactly one human-approved specification per project is operative; all else is evidence, interpretation, or candidate [N07; GF1B-N18].
- **P3 Layered authority separation.** Evidentiary, interpretive, operative, working, disclosure, and provenance roles never share a file [N05,N06,N08].
- **P4 Weakest-surface viability.** The core must run on plain dialogue via manual/semi-manual flows, and only exploit stronger surfaces additively [N02,N03; CB-01…06; S-02].
- **P5 Human-gated staging.** Every state mutation passes a human gate in v0.1; automation is deferred, never assumed [N11; CB-11,16; S-04,S-05].
- **P6 Model replaceability.** Tool-agnostic Markdown/Git core with thin generated adapters; no vendor syntax in the core [N09,N10; CB-22].
- **P7 Preservation without exposure.** Verbatim preservation is mandatory; in-repo storage is not — placement is a governed parameter, derivations never substitute originals [N06; GF1B-N14; CB-15,20; DP-07].
- **P8 Designed-in evaluability.** State is observable, claims carry evidence paths, staleness is markable, provenance is recorded [N19; CB-13].
- **P9 Handoff as artifact.** Continuity is carried by explicit relay artifacts, never by platform session memory [N12+delta; CB-06,10].
- **P10 Self-application.** The meta-agent workspace runs on this same architecture; its own history is the first test bed [N12; instrument-informed].
