# v0.1 Scope and Consistency Check / v0.1 范围与一致性检查

## v0.1 目标

Mnemosyne v0.1 是一个可继续迭代的最小设计工作仓库，不是完整自动化系统。

## v0.1 已包含

- 定位：记忆系统元 Agent 设计仓库。
- 外部记忆架构：模型负责计算，文件负责记忆。
- 语言策略：中文正文为主。
- 执行源原则：Human-Approved Spec 为执行源，其它层非执行源。
- 核心对象模型：raw/candidate/similarity/spec/decision/open question/todo/handoff + 未来对象占位。
- 对象模板与 ID / 状态规则：已形成草案。
- 需求进入流程：raw -> candidate -> compare -> 用户确认 -> spec。
- handoff / active-context / 阶段性回顾机制：已形成草案。
- 模型迁移与约束生命周期：已形成草案。
- 交付包原则：面向目标项目交付结构已定义。
- 半自动工作流：用户确认 + Codex 小步写仓库。

## v0.1 明确不包含

- 自动查重
- 自动索引
- 自动 ID 生成
- 自动 schema 校验
- 自动写回
- 自动交付
- 自动 drift 检查
- 自动模型迁移
- 自动 raw 重分析
- GitHub Actions
- AGENTS.md
- CLAUDE.md
- MCP
- RAG
- 多 Agent 自动协调
- 真实目标项目自动化交付实施

## 一致性检查清单

- [ ] raw 是否被误写成执行源
- [ ] candidate 是否被误写成执行源
- [ ] handoff / active-context 是否被误写成执行源
- [ ] human-approved-spec 是否被明确为执行源
- [ ] 是否把未来功能写成已完成
- [ ] 是否出现英文正文或双语正文
- [ ] TODO 和 open questions 是否有重复
- [ ] handoff 是否反映最新阶段
- [ ] active-context 是否反映最新阶段
- [ ] README 是否准确描述仓库
