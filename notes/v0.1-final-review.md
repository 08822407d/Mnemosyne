## 7. v0.2 第一方向候选

### A. 目标项目记忆系统模板

用于让 Mnemosyne 开始为具体项目生成 memory system design spec、delivery manifest、target project intake 等模板。

### B. self-improvement workflow

用于把“用户新构想 / 使用反馈 → raw → candidate → similarity/conflict → 用户确认 → spec/todo/open question”的流程细化为可执行操作。

### C. 研究报告 summary / Evidence Item

用于把 7 份研究报告进一步拆成可索引、可追溯、可 refresh 的 evidence item。

### D. Idea Capture Buffer

用于支持用户临时速记粗糙点子，再由 Mnemosyne 后续整理、查重和转入候选需求。

### E. AGENTS.md / CLAUDE.md 适配

用于让 Codex / Claude Code / 其他 coding agent 更稳定地读取仓库规则，但应等当前 v0.1 稳定后再做。

### F. GitHub Actions 轻量文档检查

用于自动检查关键文件是否存在、是否含有执行源声明、是否有明显过期状态，但属于后续自动化。

## 8. 推荐排序

保守推荐排序：

1. 用户最终 review；
2. self-improvement workflow 或目标项目记忆系统模板二选一；
3. 研究报告 summary / Evidence Item；
4. Idea Capture Buffer；
5. AGENTS.md / CLAUDE.md；
6. GitHub Actions / 自动化。

排序理由：

- 当前 Mnemosyne 已能接手，但还需要先决定它下一步是“服务自身迭代”还是“开始服务目标项目交付”；
- 自动化应晚于流程稳定；
- AGENTS.md / CLAUDE.md 应晚于核心工作流确认；
- 研究报告 summary 有助于减少后续模型对 PDF 的依赖。
