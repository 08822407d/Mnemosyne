# 盲评共用细则（MNE-DR-030 / MNE-DR-031 通用，预冻结）

```yaml
record_type: preregistered_review_rubric
frozen_at: 2026-08-31（本文件提交入库即冻结；两位评审者读到的必须是同一哈希版本）
derivation: 全部条款派生自先于两份设计稿存在的三源——工作令 §3 阶段2 必含清单、目标登记表（01，含 §4 验收标准草案）、反模式清单 v1；起草者为 Fable（利益相关方），派生纪律=不新增三源之外的评价维度
scoring: 每项 PASS / PARTIAL / FAIL ＋两句内短评；不打总分（分数只是证据）；盲评=只评手中一稿、不做两稿比较（比较权在 Owner）
```

## 评审项（R1~R8）

| # | 评审项 | 判定依据 |
|---|---|---|
| R1 | 必含十二节齐全且实质（架构/文件组织/三态循环/状态机/加载投影/目的核查/Owner-touch/交接＋预冻结测试/迁移/反模式自检/自我批判/证据引用） | 工作令 §3；缺节或空壳节=FAIL |
| R2 | 公理遵从：N-14/15/17/18/19 与 X-1~X-4 裁定逐条落实 | 02a 裁决原文；违背任一裁定=该项 FAIL |
| R3 | 证据接地：关键结论可回溯到材料（报告/登记表）；无据断言是否诚实标注 INFERENCE/UNKNOWN | 抽查 ≥10 处关键主张 |
| R4 | 核心目标方案质量：交接方案是否覆盖五元恢复、不可重推隐藏依赖、按接收方分层、拒收与反陷阱；预冻结测试是否可执行（样本/判分/统计纪律） | 登记表 §4.1＋工作令 |
| R5 | 反模式自检真实性：16 条是否实质对冲（有机制）而非口号 | 反模式清单 v1 |
| R6 | Owner 负担：touch 预算是否现实、提问三件套/人话呈现是否内建 | 登记表 N-09/N-18＋§4.5 |
| R7 | 可实施性：迁移计划可回滚、成本估计诚实、与现状兼容路径清楚 | 工作令"自现状迁移" |
| R8 | 自我批判质量：盲区识别是否触及真风险（含同族偏置、复杂度反噬） | 反模式 #3/#14 |

## 交付格式（评审者）

逐项 R1~R8 表＋**三大优点/三大缺陷**（各配证据位置）＋**采纳建议清单**（该稿中建议进入最终合成稿的具体机制，逐条注明出处节号）＋evidence 标签纪律（VERIFIED/INFERENCE/UNKNOWN）。
