## 1. 背景与用途

一个长期人机协作项目在 2026-05 以"类冯诺依曼"类比为总体抽象建立了外部持久记忆体系：**模型像 CPU（可替换的无状态计算单元）、对话上下文像 RAM、外部 Git 文件像硬盘（唯一长期真相源）、规则文件像程序、交接包像进程快照**。项目主人最近自省：该类比是早期缺乏依据的构想、"想象成分很大"、从未仔细复核——已裁定在新方案确定前沿用，但要求研究**是否存在更适合的总体抽象模型**。本报告即该复核的证据输入。注意：项目已另行掌握"记忆机制层"的盘点（压缩/文件/向量/图/checkpoint 等），**本课题问的是更高一层的"总体抽象/组织隐喻"**，不要退化成机制罗列。

## 2. 研究问题

**Q1 · 候选总体抽象盘点**：2024-2026 学界与业界为"长期运行的 LLM agent 系统"提出过哪些总体抽象/参考架构？至少核查：操作系统类比（如 MemGPT 的 LLM-as-OS：主存/外存分页）、认知架构类比（SOAR/ACT-R 传统及 CoALA 等 LLM 时代框架：工作记忆/情景/语义/程序性记忆分型）、事件溯源/账本模型（append-only log ＋投影视图）、黑板模型（多 agent 共享工作区）、数据库中心模型、以及"文件即真相"的 Git/文档中心模型。每个：核心主张、代表实现、实证或采用度、已知批评。

**Q2 · 冯诺依曼类比的适配性批判**：该类比在哪些方面与 LLM 实际不符或产生误导（如：模型并非无状态确定性 CPU、上下文并非可随机寻址 RAM、"指令/数据分离"在提示注入现实下的边界、缓存类比与注意力机制的差异）？哪些方面仍然站得住（可替换性、外部化、可审计）？有没有公开文献直接讨论过这类比喻的利弊？

**Q3 · 人机长期协作的特殊要求**：与纯自动 agent 相比，"人类 owner ＋多家可替换模型＋跨年工作"的场景对总体抽象提出哪些额外要求（人的记忆局限、授权边界、模型换代迁移、多写入方）？哪个候选抽象对这些要求覆盖最好？

**Q4 · 混合与分层的先例**：有没有把多种抽象分层组合的成熟先例（如：账本层＋投影层＋工作记忆层）？组合的代价（复杂度、一致性）有何证据？

**Q5 · 结论**：给出对照表——各候选抽象在【模型可替换性/可审计性/人类可读性/当前态管理/加载效率/迁移成本/与现状兼容】各维度的证据化评价；指出"沿用现类比＋定点修补"与"换用某候选"两条路线各自的证据支持度。**不做最终裁决**（那是委托方设计阶段的工作）。
