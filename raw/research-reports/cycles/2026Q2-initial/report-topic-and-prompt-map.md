## 文件定位

本文件映射 `RC-2026Q2-initial` 的 7 份 report 与对应研究课题 / prompt 状态。本文件不是执行源，不是研究报告原件，不是 summary，也不替代 research motivation。

当前执行源仍是 `current/human-approved-spec.md`。如本文件与执行源冲突，以执行源为准，并登记 open question。

## 使用规则

- prompt available 时可用于理解研究输入。
- prompt missing 时只能使用 report title / summary / motivation 推断研究课题。
- 不得把 inferred topic 说成 user original prompt。
- 研究结论仍以 report / summary / evidence map 为依据。
- prompt 不作为执行源。
