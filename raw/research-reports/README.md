# Research Reports / 研究报告证据目录

本目录用于保存**具有时效性**的深度研究报告证据。

## 目录定位

- 研究报告属于 **raw 证据层**，用于支持能力边界判断、候选需求提炼与后续复核。
- 研究报告**不是执行源**。
- 当前执行源仍是 `current/human-approved-spec.md`。

## 版本与轮次原则

- 研究报告按 `research cycle` 管理，不平铺覆盖。
- 旧报告不可被新报告直接覆盖。
- 新研究进入新轮次（cycle），并通过索引、evidence-map、delta 比较建立关系。
- 旧证据可标记状态（如 superseded / deprecated / confirmed），但应保留历史记录。
